# Food Order Builder

A small **Vanilla JavaScript practice project** built to strengthen my understanding of JavaScript by creating a functional food-ordering interface.

## Technologies Used

* HTML5
* CSS3
* Vanilla JavaScript

## What I Practiced

### JavaScript

* Variables
* Constants
* Conditions
* Loops
* Functions
* Arrays
* Array methods
* Objects
* Object property access
* Scope

### DOM Manipulation

* Selecting HTML elements
* `getElementById()`
* `getElementsByName()`
* `querySelector()`
* `.value`
* `.checked`
* `innerText`
* `innerHTML`
* `createElement()`
* `append()`
* `remove()`
* Dynamic element creation
* DOM traversal
* Parent and child elements

### Events

* `addEventListener()`
* `click` events
* `submit` events
* Event object
* `event.target`
* `preventDefault()`
* Event bubbling
* Event delegation
* `stopPropagation()`

### Forms

* Form submission
* Input fields
* Number inputs
* Select dropdowns
* Checkboxes
* Reading form values
* Checking selected checkboxes
* Collecting selected values into arrays

## Project Features

* Select food items and sizes
* Choose multiple extras
* Set quantity
* Add special instructions
* Automatically calculate item prices
* Calculate the overall order total
* Add multiple orders
* Edit existing orders
* Delete orders
* Dynamically create and update order cards
* Display an empty-order message when there are no orders

```text
food-order-builder/
```

## Purpose

This project was created purely as a **JavaScript practice project** to apply JavaScript concepts in a working web application and understand how JavaScript interacts with HTML, the DOM, events, and forms.
